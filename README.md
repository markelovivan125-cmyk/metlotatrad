# Радар осадков · Россия

Одностраничный сайт-радар: композитные данные метеорадаров по России с анимацией,
настоящим вертикальным срезом, данными клетки, линейкой и 3D.

- **Карта:** OpenStreetMap; библиотеки OpenLayers, proj4 и Three.js встроены в `index.html`,
  интернет нужен только для тайлов карты и кадров радара.
- **Код:** `index.html` — собранная и обфусцированная сборка; исходники не публикуются.

## Источники данных

- **Отражаемость · композит (сейчас)** — композитная отражаемость, срез 1 км (dBZ),
  Европейская часть / Сибирь / Дальний Восток / вся Россия.
- **Наукастинг осадков · прогноз 2 ч** — прогноз интенсивности осадков (мм/ч) по Европе России.
- **Высота ВГО** — высота верхней границы облачности (км).
- **Данные BUFR · опасные явления** — классификация явлений: осадки, ливни, грозы, град, шквалы.
- **Доплер · радиальная скорость 1 км** — радиальная скорость (м/с).
- **Явления погоды · 3 ч (на карте)** — карта метеоявлений ЦАО, наложенная на OSM.

## Возможности

- Анимация кадров с шагом 10 минут; пауза, скорость 0,5×/1×/2×, кнопка «Сейчас»;
  новые кадры подхватываются автоматически.
- Регионы: Европейская часть, Сибирь, Дальний Восток, вся Россия; прозрачность слоя; легенды по каждому продукту.
- **Линейка** — расстояния по геодезической: клик ставит точки, двойной клик завершает, Esc выходит.
- **Данные клетки** — клик по карте: значение в клетке (dBZ / мм/ч / класс явления / м/с),
  класс осадков, координаты; значения обновляются вместе с анимацией.
- **Вертикальный срез** — проведите линию по карте (двойной клик завершает): строится настоящий
  разрез по объёмным радарным данным — высота 0–11 км по вертикали, расстояние по горизонтали,
  выбор величины: Отражаемость / ZDR / Скорость. Работает при локальном запуске.
- **3D-срез** — поверхность интенсивности над картой (высота поверхности = dBZ).
- **Снимок** — кнопка «Снимок» скачивает текущий вид карты с легендой, временем и подписью OSM (PNG).
- **АСТОРП** — серия авторисков: «Вся Россия», по очереди композит, ВГО, явления, доплер,
  сумма 12 ч, прогноз суммы, наукастинг — каждый кадр отдельным PNG `astorp_….png`.
- **Автоснимки** — галочка «Автоснимки каждые 10 мин»: текущий вид сохраняется автоматически.
- Горячие клавиши: **Пробел** — пуск/пауза, **← / →** — по кадрам, **Home/End** — первый/последний,
  **Esc** — закрыть панели и инструменты.

## Запуск на своём компьютере

Открывать `index.html` двойным кликом **не нужно** — браузеры блокируют часть запросов со
страницы `file://`. Вместо этого:

1. Дважды щёлкните **`start.bat`** — поднимется локальный мини-сервер (только 127.0.0.1,
   наружу не смотрит) и сайт откроется в браузере.
2. Закройте окно сервера, когда закончите.

## Публикация в интернете

Достаточно загрузить **один файл `index.html`** на любой статический хостинг (GitHub Pages,
свой nginx, S3 и т. п.).

Просмотр карты, легенды и анимация работают отовсюду. Чтение пикселей и срезы (данные клетки,
вертикальный разрез, 3D) доступны только при локальном запуске через `start.bat`: источники
кадров не разрешают чужим страницам читать свои изображения (CORS), а статический хостинг
не умеет проксировать запросы. В публичной версии эти режимы показывают подсказку.

## Публикация на Vercel

В репозитории есть готовые серверные функции (`api/`) и `vercel.json`. Импортируйте проект в Vercel
(Other, без сборки) — WMS-продукты, клетка, срез, 3D и снимки будут работать и на хостинге,
потому что запросы идут через `/nc/*` и `/proxy` того же origin.

На статическом хостинге без функций (GitHub Pages) WMS/клетка/срез/3D покажут подсказку —
нужен либо Vercel, либо локальный `start.bat`.

## Структура

- `index.html` — готовый сайт (все библиотеки, стили и скрипты внутри; код обфусцирован).
- `start.bat`, `serve.ps1` — локальный запуск; адреса источников в прокси хранятся в base64.
- `api/` — серверные функции Vercel (прокси `/nc/*` и `/proxy`); адреса источников — в base64.
- `vercel.json` — маршруты Vercel.
- `README.md` — этот файл.
